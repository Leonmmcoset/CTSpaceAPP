# 功能覆盖

「原生」表示 Flutter 页面和 API 交互已实现；不代表已经使用真实账号对生产环境执行写操作。具体测试范围见 [VALIDATION.md](VALIDATION.md)。本项目面向普通用户和开发者，不包含管理员后台。

| 模块 | 原生能力 | 补充与边界 |
| --- | --- | --- |
| 认证 | 图文验证码、独立 isolate PoW、登录、安全问题二次验证、注册、重发激活邮件、找回用户名/密码、填写邮件令牌重置 | 邮件激活链接通过官网完成；系统安全存储不可用时显示错误 |
| 社区 | 最新/热门/话题筛选、讨论双栏、帖号跳转、回复与引用、编辑删除、举报、点赞收藏、表态、评论、投票 | 置顶锁定等管理操作不包含在用户客户端 |
| 编辑器 | 可视化富文本、Markdown 源码、预览、图片附件、网盘、标签、投票、本地草稿、恢复和退出保存 | 含表格、HTML 等不能无损转换的内容保留源码编辑；不自动重试发布 |
| 作品 | 列表/分类/搜索、发布编辑、sb3/封面上传、版本更新与历史、下载、作品网址和别名管理、评论互动 | 官方网页试玩；禁用下载时各版本均不提供源码下载入口 |
| 扩展 | 列表筛选、发布编辑删除、源码阅读与下载、许可、评论点赞 | 只展示源码，不在客户端执行扩展代码 |
| 社交 | 用户主页、关注/粉丝、排行榜、搜索、话题关注、收藏、通知、签到、积分转账、资料头像编辑 | 签到提供状态与操作，未实现月历；资料页讨论加载最近一页 |
| 搜索 | 讨论、回复、作品、扩展、用户与分页 | 通过官网实际使用的复数分类名请求；回复结果打开所属讨论 |
| 私信/群聊 | 会话、好友申请、群邀请、建群与成员管理、图片、引用、撤回、转发、转账、群红包 | Socket.IO 重连补取、按 ID 去重；离线时轮询，后台暂停；未实现操作系统推送通知 |
| 云盘 | 列表、容量、上传、重命名、删除、覆盖更新、分享、直链、公开性/密码设置、重生成、密码分享访问 | 覆盖更新保持原分享 ID；保存使用平台文件选择器 |
| 开发者 | API Key 创建/列出/撤销、一次性显示密钥、云变量项目、生产/开发环境、变量历史/重置/轮换、连接信息 | API Key 权限修改使用官网补充入口；没有实现独立云变量 WebSocket 调试终端 |
| 商城 | 商品和规格、积分/现金/混合支付、地址选择、确认下单、支付跳转/二维码/HTML、订单、取消、确认收货、地址管理 | 实际支付由支付页面处理；无自动重复下单；发行包需要配置正式签名 |
| OrigMark | 公开/我的登记、搜索、详情、服务器证书签名验证、分享、下载申请、原文件权限请求、侵权举报、作者下载/同步审批、预览开关 | 新登记与预览使用官方入口。登记 DTO 缺少字段，未猜测实现外部/论坛作品登记；独立官网在本次检查中返回 521。没有本地 RSA 离线验证 |
| 直播 | 当前场次、在线人数、聊天历史、问答、抽奖参与、Socket.IO 和断线补取 | 官方网页播放，未自行实现官网特有的 HLS loader；当前公开接口无直播场次，实时互动尚待有场次时联调 |
| 客服 | 新建咨询、会话、发送消息、前台轮询、关闭咨询 | 不包含客服工作台与管理员分配 |
| 素材 | 分类/搜索/分页、我的发布、角色和 SVG 上传、详情、文件下载、分享、删除 | 角色显示服务端缩略图，SVG 以文件下载为主；未实现素材包内部编辑 |
| 小游戏 | 列表/搜索/分页、我的发布、HTML/ZIP 上传、详情、分享、删除 | 在官方隔离网页播放器中运行，未增加原生代码执行入口；尚未提供独立封面上传控件 |
| 装扮 | 头像框、内置/已购横幅、自定义横幅开通续费和上传、主页横幅显示 | CSS 复杂纹理简化为对应配色；头像框展示渐变，不复刻官网持续旋转和发光 |
| 设置 | 系统/浅色/深色主题、动态取色、主题色、政策、开源许可、更新日志、密码/邮箱/用户名、安全问题、会话设备 | 不包含后台站点配置 |
| 财务 | 公开收支总额与明细 | 金额以分转元显示 |

五端共用业务能力，通过导航、栏数、内容宽度、文件选择和网页打开方式适配设备。桌面支持 Ctrl/Cmd+K 搜索及窗口大小记忆。
